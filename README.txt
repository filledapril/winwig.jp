WIG. Salon Professional Supply - Local Preview

1. Unzip this folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. For live preview, install the VS Code extension "Live Server".
5. Right-click index.html and choose "Open with Live Server".
   You can also double-click index.html to open it directly in a browser.

Notes:
- This is a single-file HTML prototype with responsive layout.
- Images load from Unsplash, so internet access is required for images.
- Replace the temporary WIG. logo, placeholder email (info@example.com), sample images,
  company details, and planned news before publishing.
- Product category filters, mobile navigation, FAQ accordion and anchor navigation work.
